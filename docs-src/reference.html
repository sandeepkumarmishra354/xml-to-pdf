Any attribute value can contain ${variables}, and most elements also accept the style attributes (font, size, color, align, …). Lengths are in points unless given a unit; see Units.

<document>

The root element. It must contain at least one <page>.

Children: <constants>, <resources>, <watermark>, <header> (at most one), <footer> (at most one), <page>, <for-each>.

<constants>

Declares named values that can be referenced as ${name}. It's allowed directly under <document>. Values from --data and --set override constants with the same name. See Variables.

<const>

AttributeValuesDefaultDescription
nameidentifierrequiredLetters, digits, _, - and ., starting with a letter or _. Must be unique.
valuetextelement textThe value. If it's omitted, the element's text content is used instead, which suits long values. It may reference other variables.
```xml All prices include VAT. ${company} reserves the right to change prices. ```

<resources>

Declares images and named styles that are referenced elsewhere by id. It's allowed directly under <document>. Resources can be used anywhere in the document, regardless of where they're declared.

<image> (resource)

AttributeValuesDefaultDescription
idnamerequiredThe name used by <img ref> and <watermark image>.
srcfile pathrequiredA PNG, JPEG or GIF file. Relative paths resolve against the XML file's directory (or --base-dir). A missing file is an error.
